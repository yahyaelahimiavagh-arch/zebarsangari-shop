# مرحله بعد: ساخت دیتابیس رایگان فروشگاه زبرسنگری

**وضعیت:** این شاخه فقط آماده‌سازی است؛ سایت زنده روی `main` دست‌نخورده مانده.

## با گوشی در Cloudflare

1. در داشبورد Cloudflare بخش **Storage & databases** (یا **Workers & Pages → D1**) را باز کن.
2. وارد **D1 SQL Database** شو و **Create database** را انتخاب کن.
3. نام را دقیقا `zebarsangari-db` وارد کن.
4. اگر پلن رایگان قابل انتخاب بود همان را انتخاب کن. **برای پروژه آزمایشی پرداخت یا ارتقای اجباری را قبول نکن.**
5. بعد از ایجاد، **Database ID** را کپی کن یا از صفحه دیتابیس اسکرین‌شات بفرست.

## بعد از ایجاد

- فایل `wrangler.d1.example.jsonc` باید با UUID واقعی تنظیم و محتوایش به `wrangler.jsonc` منتقل شود.
- فقط سپس migration را روی دیتابیس Remote اجرا می‌کنیم:
  `npx wrangler d1 migrations apply zebarsangari-db --remote`
- تست خواندن از API: `/api/health` و `/api/products`.
- قبل از تغییر دادن پنل نمایشی، باید ورود امن با نشست سروری و مجوزها اضافه شود؛ **نباید endpoint تغییر محصول بدون احراز هویت ایجاد کنیم.**
- عکس‌ها به ذخیره‌سازی جداگانه نیاز دارند و هنوز متصل نیستند؛ R2/KV فقط بعد از بررسی پلن رایگان و نیاز به اطلاعات پرداخت انتخاب می‌شود.
- سفارش/پرداخت واقعی هنوز فعال نشده است.

## امنیت

- هیچ پسورد، API Token، کلید دسترسی یا اطلاعات کارت را در GitHub ذخیره یا ارسال نکن.
- Database ID یک شناسه است، نه رمز عبور.
- قبل از نهایی‌شدن پنل، محصول آزمایشی و داده مشتری واقعی وارد نکن.
