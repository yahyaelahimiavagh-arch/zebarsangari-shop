# چک‌لیست تست نسخه پنل زبرسنگری

**این نسخه برای آزمایش فروشگاه است؛ هنوز پرداخت و ثبت سفارش فعال نیستند.**

## پیش‌نیازها
- در D1 جدول‌های `products`, `product_variants`, `product_images` و `admin_login_attempts` وجود دارند.
- نام Secretهای Cloudflare دقیقاً `ADMIN_PASSWORD` و `SESSION_SECRET` است؛ اولی حداقل ۱۲ و دومی حداقل ۳۲ کاراکتر دارد (توصیه: رمز مدیریت ۲۰+ کاراکتر تصادفی).
- KV با Binding دقیق `IMAGES` به Worker وصل شده است.
- نسخه GitHub منتشر و آخرین Deployment در Cloudflare سبز شده است.

## تست‌های عملکرد و امنیت
1. صفحه اصلی را باز کنید؛ چون D1 خالی است، پیام «هنوز محصولی در این دسته ثبت نشده است» می‌بینید. کالاهای نمونه و قیمت‌های ساختگی نباید نمایش داده شوند.
2. در پنجره ناشناس، `/api/admin/me` باید JSON با HTTP 401 بدهد؛ اطلاعات محصولات دیگران قابل‌ویرایش نباشد.
3. به `/manage.html` بروید و با رمز مدیری که فقط در Cloudflare Secret ثبت کرده‌اید وارد شوید.
4. یک محصول تست با عنوان «محصول آزمایشی — منتشر نشود» بسازید؛ ابتدا تیک نمایش را بردارید. دو تنوع سایز/رنگ و موجودی مجزا تعریف کنید.
5. پس از ذخیره، در پنل لیست محصول را مشاهده و ویرایش کنید. صفحه فروشگاه هنوز نباید آن محصول را نشان دهد.
6. یک تصویر کمتر از ۶۵۰ کیلوبایت آپلود کنید؛ پنل تلاش می‌کند عکس را فشرده کند. ممکن است تصویر در نقاط مختلف Cloudflare تا حدود ۶۰ ثانیه دیرتر دیده شود.
7. محصول تست را فعال کنید و از مرورگر دیگری صفحه اصلی را باز کنید؛ نام، قیمت، عکس و موجودی را بررسی کنید.
8. سایز/رنگ ناموجود نباید به سبد آزمایشی اضافه شود. دکمه پرداخت همچنان غیرفعال است.
9. از پنل خروج بزنید؛ دوباره `/api/admin/me` باید HTTP 401 بدهد.
10. پس از پایان آزمایش، محصول آزمایشی را غیرفعال کنید.

## اگر خطا دیدید
- HTTP 503 با `admin_not_configured`: Secretها یا Binding D1 را بررسی کنید، رمزها را در چت/اسکرین‌شات نفرستید.
- `login_rate_limit_not_ready`: جدول `admin_login_attempts` وجود ندارد یا migration اجرا نشده است.
- `image_store_not_configured`: KV با نام `IMAGES` هنوز به Worker متصل نیست.
- صفحه سفید/اشکال 404: آخرین GitHub deployment و `wrangler.jsonc` را بررسی کنید.
- خطای 429: تلاش‌های ورود زیاد بوده؛ از تغییرات اضافی رمز یا درخواست‌های مکرر خودداری کنید.

**هشدار:** هیچ API پرداخت، ذخیره سفارش مشتری، کاهش موجودی هنگام خرید، تسویه مالی و حساب مشتری در این نسخه فعال نیست. فروش واقعی را شروع نکنید.
